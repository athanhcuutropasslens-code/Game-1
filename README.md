# Pixel Rogue - RPG Game

Một trò chơi nhập vai (RPG) theo lượt với giao diện Retro Arcade Cyberpunk. Người chơi có thể chọn lớp nhân vật, khám phá các khu vực, chiến đấu với quái vật, và nâng cấp trang bị.

## Tính Năng

- **4 Lớp Nhân Vật**: Chiến Binh, Sát Thủ, Pháp Sư, Mục Sư
- **Hệ Thống Chiến Đấu**: Dựa trên Rock-Paper-Scissors với hiệu ứng trạng thái
- **Quản Lý Trang Bị**: Vũ khí, giáp, phụ kiện với hệ thống affixes
- **Khám Phá Khu Vực**: 4 khu vực với độ khó tăng dần
- **Hệ Thống Kỹ Năng**: Mỗi lớp có kỹ năng riêng để nâng cấp
- **Cửa Hàng**: Mua bán vật phẩm, hồi phục, mở hộp kho báu

## Cách Chơi

1. Chọn lớp nhân vật phù hợp với phong cách chơi của bạn
2. Chọn khu vực để khám phá
3. Điều hướng qua các phòng trên bản đồ
4. Chiến đấu với quái vật bằng cách chọn hành động (Búa/Bao/Kéo)
5. Thu thập loot, nâng cấp chỉ số, và cải thiện trang bị
6. Chinh phục các tầng cao hơn để thử thách bản thân

## Công Nghệ

- React 19 + TypeScript
- Tailwind CSS 4
- Vite
- shadcn/ui

## Cài Đặt

```bash

pnpm dev
```
